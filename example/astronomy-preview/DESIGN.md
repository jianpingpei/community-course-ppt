# 天文短预览设计

仅5页、预计5分钟，显式短预览，不代表完整课时。和生物课程使用独立源码，不加载生物样式。

采用天文观测手记的版面：暖白背景、午夜蓝文字、锈橙强调；中文宋体，西文Georgia。左右边距0.7英寸，标题34pt，正文26pt，来源14pt；封面课程名18pt，主题44pt。所有图形原生可编辑，无现成模板或装饰照片。

1. 封面：大字观察问题＋旋转轮廓的原生线图。
2. 输入：像素强度格＋观测条件解释。
3. 对称性：同轮廓三种朝向的横向对比，保持空间比例。
4. 方法：旋转视角、共享卷积特征、汇总预测的三段真实流程。
5. 回顾：研究对象、输入、方法、评测的对齐清单。

图中的像素阵列和轮廓为讲授对称性而构造，不是观测或模型测量；此说明保存在元信息，不加入听众页面。没有使用真实星系照片，也不陈述性能数字。依据来源为Dieleman等人2015年论文的摘要与方法主线。
